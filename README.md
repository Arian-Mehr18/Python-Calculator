# Python Calculator

A simple command-line calculator built with Python.

## Features
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Supports multiple numbers
- Input validation
- Division by zero handling
- Continuous calculations
- Quit option

## Technologies
- Python 3
- Functions
- Loops
- Exception Handling
- List Comprehension

## How to Run

```bash
python calculator.py
```
